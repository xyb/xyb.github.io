Cardputer MP3 播放器

版本 0.1.0 · 构建 116dac6 · 2026-10-05 23:53:06

用 Chrome 或 Edge 打开这个页面。用数据线把 M5Stack Cardputer 接到电脑，点下面的按钮，在弹出的窗口里选中这块板子。

写入的是引导程序、8 MB 分区表，以及播放器本身。播放器写在第一块程序槽，下次从这里启动。已经保存的音量和 WiFi 会留着。

这个浏览器不能直接写设备。请换 Chrome 或 Edge。 这个页面需要通过 https 打开。在自己电脑上试，可以用 localhost。

适合 Cardputer ADV，也适合原版 Cardputer。芯片是 ESP32-S3。
